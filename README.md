# CS 536: Spring 2026 Assignments

This repository contains the collaborative programming assignments and projects for **CS 536** at Purdue University during the Spring 2026 semester.

**Course Website:** [https://stygianet.cs.purdue.edu/courses/2026springcs536.html](https://stygianet.cs.purdue.edu/courses/2026springcs536.html)

## Directory Structure

* **`hw1/`** - A network measurement tool that correlates network latency (RTT) with physical distance by geolocating and pinging various iperf3 servers.
* **`hw2/`** - A Python socket application that extracts real-time TCP statistics to train an ML model, which is then used to design a custom congestion avoidance algorithm.
* **`hw3/`** - An evaluation of the custom congestion control algorithm, implemented either natively as a Linux kernel module or simulated within an NS-3 datacenter topology.

## Getting Started

Because each assignment involves different tech stacks and execution environments, there are no centralized setup instructions. 

To get started, please navigate to the specific assignment directory (e.g., `hw1/`, `hw2/`) and read the individual `README.md` file located inside for detailed build instructions, dependencies, and run commands.
